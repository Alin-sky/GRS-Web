# 敏感词语义标注指南

## 为什么要标注

预检系统通过词库 + 拼音匹配检测敏感词，但会产生误报：
- "菠菜"匹配到赌博暗语，但可能是蔬菜名称
- "上岸"匹配到赌博术语，但可能是考公成功
- "金沙"匹配到赌场名称，但可能是地名

标注后，AI 会收到每个词的**真实含义、误报场景、高风险场景**，从而做出更准确的判断。

## 标注写在哪里

文件：`data/sensitive_words.json` → `word_contexts.entries` 字段

```json
"word_contexts": {
  "entries": {
    "敏感词": {
      "meaning": "该词的真实含义",
      "false_positive_patterns": ["容易误报的场景1", "容易误报的场景2"],
      "high_risk_patterns": ["真正高风险的场景1", "真正高风险的场景2"]
    }
  }
}
```

## 字段说明

| 字段 | 必填 | 说明 | 示例 |
|---|---|---|---|
| `meaning` | 是 | 该敏感词的真实含义，说明它为什么是敏感词 | `"赌博游戏中指'博彩'的谐音暗语"` |
| `false_positive_patterns` | 否 | 容易被误报为该敏感词的正常使用场景 | `["烹饪讨论（如菠菜炒鸡蛋）"]` |
| `high_risk_patterns` | 否 | 真正构成违规的高风险场景 | `["与赔率、盘口等赌博术语同现"]` |

## AI 收到的效果

**无标注时**，AI 收到：
```
[赌博] "菠菜" (直接匹配)
注意：以上匹配可能为误报，请结合上下文判断。
```

**有标注后**，AI 收到：
```
[赌博] "菠菜" (直接匹配)
  语义: 在赌博语境中指'博彩'的谐音暗语，但也可能是正常蔬菜名称
  误报场景: 烹饪/食谱讨论（如'菠菜炒鸡蛋'）；营养价值/健康饮食讨论；农产品/买菜相关话题
  高风险场景: 与赔率、盘口、下注等赌博术语同现；与菠菜中介/菠菜平台等组合出现

以上部分敏感词附带了语义标注，请优先参考标注信息判断：
- 如果文本符合"误报场景"描述，应判定为安全或降低风险等级
- 如果文本符合"高风险场景"描述，应判定为对应风险等级
```

## 标注优先级

按 P0 → P2 顺序标注，不用一次性标完所有词：

| 优先级 | 哪些词 | 原因 |
|---|---|---|
| **P0** | 拼音匹配容易误报的词（如"为你"→"维尼"） | 直接解决当前误杀问题 |
| **P1** | 有多重含义的高频词（如"菠菜""上岸""金沙"） | 影响范围大 |
| **P2** | 含义单一、不太会误报的词（如"百家乐""赌场"） | 边际收益低，可不标 |

## 标注步骤

1. 打开 `data/sensitive_words.json`
2. 找到 `word_contexts.entries`
3. 添加或修改对应词的标注
4. 保存即可，系统下次审核时自动读取（词库有缓存，可重启服务或调用 `/api/precheck/reload` 热重载）

## 注意事项

- 只标注 `word_contexts.entries` 中出现的词，不需要在 `categories` 的 `words` 列表里重复
- `meaning` 写一句话即可，简明扼要
- `false_positive_patterns` 和 `high_risk_patterns` 每条写一个场景，用数组
- 不确定的词可以先不标，AI 会回退到默认提示逻辑
